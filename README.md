📚 Study Habits Analysis
📌 Project Overview
This project analyzes my daily study habits using Python and Statistics to understand patterns in study time, focus, subjects, and study routines.

The analysis was performed using a personal study dataset collected over multiple days.

🎯 Objectives
Analyze daily study hours and study patterns
Understand the relationship between study time and maximum focus time
Compare study hours across different subjects
Compare study days with days off
Analyze the distribution of study hours
Explore the relationship between start time and focus time
Identify correlations between numerical variables
Extract key statistical insights from the dataset

🗂️ Dataset
The dataset contains information about daily study sessions, including
Date
Study Hours
Maximum Focus Time
Start Time
End Time
Subject
Day Off
